Use this document to verify split-view scroll synchronization after changes to the editor, preview renderer, Markdown parser, or code highlighting pipeline.

## Checks

1. Scroll the editor from top to middle to bottom. The preview should follow the same document region without bouncing.
2. Scroll the preview from bottom to middle to top. The editor should follow the corresponding source line.
3. Quickly flick-scroll each panel. The opposite panel should update once per animation frame without feedback loops.
4. Put the caret at the final line and type continuously. The preview should stay near the final rendered block and must not jump to the middle.
5. Select or click different editor lines. The preview should move to the matching rendered block when scroll sync is enabled.
6. Resize the app horizontally and vertically. The current document position should remain stable after preview height changes.
7. Verify headings, paragraphs, nested lists, code blocks, tables, blockquotes, images, Mermaid, and KaTeX blocks all keep source-line mapping.
